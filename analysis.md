## 1. What is a stack?
A stack is a linear data structure that follows LIFO (Last In, First Out). Its basic operations include push, pop, and peek.

## 2. What is a queue?
A queue is a linear data structure that follows FIFO (First In, First Out). Its basic operations include enqueue and dequeue.

## 3. What is the difference between an array stack and a linked stack?
An array stack stores elements in a list with a capacity limit in this project. A linked stack stores elements in nodes connected by references.

## 4. What is the difference between an array queue and a linked queue?
A circular array queue uses a fixed-size list and reuses positions as items are removed. A linked queue connects nodes and tracks the front and rear.

## 5. What is stack overflow?
Stack overflow happens when an item is pushed onto a stack that has reached its capacity.

## 6. What is stack underflow?
Stack underflow happens when a pop operation is attempted on an empty stack.

## 7. What are real-world applications of stacks?
Stacks are used for undo operations, browser history, expression evaluation, and checking balanced parentheses.

## 8. What are real-world applications of queues?
Queues are used in printer scheduling, task scheduling, customer service systems, and data buffering.

## Conclusion
Stacks and queues organize data in different orders. A stack processes the most recently added item first, while a queue processes the earliest added item first.
